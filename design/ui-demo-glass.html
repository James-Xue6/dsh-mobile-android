v3 打磨了什么

① 折射高光（斜射层）
从左上方打一束 135° 白色渐变 —— 这是"玻璃"和"磨砂塑料"的最大区别，v2 缺这层所以发闷。
② 磨砂噪点
每块玻璃自带 fractalNoise 细噪点（soft-light 混合），表面有颗粒感，不再像纯色贴片。
③ 内发光
边缘一圈 inset 0 0 26px 淡白雾，让玻璃"厚"起来 —— 真实玻璃边缘的观感。
④ 双层投影
近处紧实的暗 + 远处大范围柔光：玻璃是"浮"在背景上的，不是贴在墙上。
⑤ 背景 6 套配色
极光 / 深海 / 暮色 / 森林 / 紫罗兰 / 素雅 —— 底部色块直接切，看哪套配玻璃最好看。
⑥ 底部控制条锁定
固定在最下方（本身也是玻璃），翻到任何一屏都能切「风格 / 主题 / 模糊 / 配色」。
