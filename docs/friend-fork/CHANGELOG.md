## v0.86.42（2026-10-06）

交接单上挂着的**待做三件**，这次一起做完：

- **新**：抽屉里的**会话搜索** —— 顶部搜索框，输入即过滤（标题 / 工作区名 / 目录名 / 预设名任一命中）
  - 行是手搓构建的，过滤统一收在 `SessionListView.applyFilter()` 这一个入口：MainActivity 那十几处 `setRows(buildRows())` 一处都不用改
  - 状态行从「已连接 · N 个对话」变成「**找到 N 条 / 共 M 条**」；搜不到时显示「没有找到「关键词」」空态（不是空白）
  - **搜索期间子会话自动展开**：子智能体/专家团会话默认折在父会话下面，不展开的话命中它也会搜不出来
  - 抽屉关掉时自动清词 + 收键盘（否则下次拉开看到的是"上次搜剩下的半截列表"）
- **新**：「＋」多了**拍照**（弹「相册 / 拍照」二选一）
  - 自己实现了个**极简 FileProvider**（`ShareProvider`，本工程没 AndroidX）：相机 App 必须拿到可写的 `content://` 地址才肯回**原图**，否则只给一张缩略图
  - 只暴露 `cache/dsh-share/` 一个目录、只认单段文件名 + canonical 复核（防目录穿越），`exported=false` + 一次性 Uri 授权
  - 拍照前先要 **CAMERA 运行时权限**（Android 11 起声明过就必须授权，否则系统直接拒绝拍摄 Intent = 点了没反应）
  - 成败按**文件**判定而不是 `resultCode`（部分 ROM 取消也回 OK）
- **新**：交付物**应用内预览**（点文件名 → `ArtifactActivity` 里的 WebView）
  - 复用现成的分块下载（sha256 校验 / 进度 / 断线判失败全白拿），只把落点从「下载目录」换成 `cache/artifact/`，WebView 直接读 `file://`
  - 能看：HTML、图片（可双指放大）、纯文本（txt/md/json/log/csv…，转义后用 `<pre>` 包一层，**跟着深浅色走**）
  - **看不了的不硬撑**：docx/xlsx/pdf/zip 给说明卡 + 「复制路径」，并提示长按文件名可以下载到手机
  - WebView 关掉 JS / DOM storage / content 访问，只放行 `file://`；页面里的外链不在本页打开
  - 文件名**保留扩展名**（WebView 按扩展名认类型，`.part` 会把 HTML 当纯文本吐出来）
- **改**：交付物行的动作分了轻重 —— **点一下 = 看**（原来的默认动作），**长按 = 菜单**（下载到手机 / 复制路径）

## v0.86.41（2026-10-06）

- **修**：`version.json` 里的下载地址曾被更新说明**撑破**（说明里用了英文引号，拼 JSON 时结构破了，说明文字挤进 `url` 字段 → App 拿着假网址下载必然失败 = 用户遇到的「更新不了」）
- **新**：发版脚本增加 **JSON 自检** —— 写完立刻解析回来，解析不了直接**中止发版**（绝不让坏清单发出去）
- **修**：备用下载地址（`mirror`）原来**写死上游作者仓库** → 主线路失败时会去下上游的包、sha256 必然对不上、更新中断；改为指向本镜像
- 更新说明统一改用中文引号，避免同类问题

## v0.86.7 ~ 0.86.14（毛玻璃改版）

- **新**：**环境光晕底**（三段线性渐变 + 四个径向光晕），替换原纯色底 —— 玻璃终于有「可透之物」
- **新**：**6 套背景配色**（设置 → 主题 → 背景配色：极光/深海/暮色/森林/紫罗兰/素雅），深浅各一套
- **改**：玻璃分层更透（卡片 88%→65%、顶栏 80%→72%、输入 92%→77%、弹层 95%→90%）
- **新**：玻璃**折射高光（斜射层）+ 内发光**
- **改**：灰色正文加深（`INK_SUB` / `INK_FAINT`），解决彩色底上「灰字看不清」
- **新**：抽屉用「**内容缩到 1/6 再双线性放大**」的廉价模糊 —— 绕开 ROM 不支持系统模糊，任何 Android 版本都出磨砂效果
- **修**：
  - 切主题/换配色 **闪退**（设置页色块列表未清空导致下标越界）
  - 抽屉「没有玻璃感」的真因 —— 抽屉里的会话列表自己铺了一层不透明环境底，把抽屉玻璃**整个盖住**
  - 顶栏「没有玻璃感」的真因 —— 上游因纯色底会「变成白横条」而**主动把顶栏玻璃关掉了**，本镜像在彩色底上把它挂回来
