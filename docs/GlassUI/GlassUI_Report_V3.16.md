## 1. ①-a 抽屉边缘那条阴影：**已定位**（量化）

沿抽屉右缘做列均值扫描（x=820…980，y=200…1400）：

```
x≈820..850: 211.8 212.5 212.3 211.5   ← 面板正常
x≈860:      203.6                      ← 【暗带】比面板暗 ~8 级
x≈870..880: 211.4 211.5               ← 回到面板
x≈890 起:   129.8 …                    ← 面板结束，外面是页面
```

**结论**：暗带位于**面板内侧约 30px（≈11dp）**，不是页面侧的东西。
来源 = **旧玻璃 drawable 的 `padFor` 内缩**：`Ui.blurredGlassRoot(bg, …)` 的模糊体比面板窄一圈，
边界处留下一个色调台阶（与 V3.9.4 修掉的那条硬边同源，这次台阶很浅）。

> 说明：这层玻璃是**旧引擎**（它才能抓到窗口背后的内容），`padFor` 在其内部；
> 调小 blurDp 能让台阶更靠近边缘、对比更低（一次性受控改动），彻底消除需要把抽屉面板换成新玻璃
> ——而新玻璃在抽屉里取样不到页面，所以**当前不动**，留作与"抽屉整体换新玻璃"一起做。
