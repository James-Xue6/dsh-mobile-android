## 2. ⚙️ 历史"只出 8 条"：根因 + 已改（自动拉全）

**根因**：会话打开时网关只给**当前窗口**（尾部若干条）的快照，**更早的历史只有用户上滑才会拉**
（`onLoadMore`）⇒ 打开会话只看得到最近几条，右侧刻度条也只能按"已加载的那几条"算轮数。

**改法**（`MainActivity`）：快照落地后**自动往上翻页拉全** ——
`autoPageStep()` 每 **200ms** 调一次**同一个** `onLoadMore()`（既有守卫全保留：
`loadingMore` / `hasMore` / `nextBeforeSeq` / `gw.canSend()`），**最多 80 页**，
**切会话或没有更多即停**。
⇒ 拉全之后 `n` = 真实轮数 ⇒ 右侧刻度条**严格按轮数对应**、也能真的跳过去。
