## 2. 「生成物」为空 —— 定性（还没改代码）

**取数逻辑（已查明）**：`collectProducedFiles()` 只扫 **`ChatItem.FILES`** 项，
而这类项**只有一个来源** —— `deliverables/presented` 事件（`MainActivity:6468-6481`）。

⇒ 所以面板列的是 **Agent 明确"交付/呈现"出来的文件**；**它不列**"Agent 写过/改过但没 present 的文件"。
如果你的那轮对话产出了文件却没有 `deliverables/presented`，面板就是空的 —— 这是**取数范围**问题，不是"点开坏了"。

**下一轮的具体做法（两条，按性价比排序）**：
1. **按会话累积已见的交付物**（内存 `Map<sessionId, LinkedHashMap<key, entry>>`）⇒ 文件滚出历史窗口后仍在面板里；
2. 接 **工作目录文件清单**这条源（`GatewayClient` 里有对应接口，但它的注释明确写着**当前没有调用点**）
   ⇒ 面板可以列出"本会话工作目录里真正产出/改动过的文件"。
