## 2. Markdown 渲染（自绘，不引第三方库）

新增 `src/com/dsh/mobile/glass/MarkdownText.kt`（约 260 行）：

- **行级**（`parseMarkdown`）：标题 `#~###`、无序列表、有序列表、**表格**（`|…|` + `|---|`）、引用 `>`、
  代码块 ```` ``` ````、分隔线 `---`、段落；
- **行内**（`inlineMarkdown`）：`` `行内代码` ``（等宽 + 底色）、`**加粗**`、`*斜体*`；
- **渲染**（`MarkdownText`）：表格按行渲染（表头加粗 + 细分隔线）、引用带左侧品牌色竖条、
  代码块带底色 + 等宽字体；
- 接入点：**助手正文**（展开态走 Markdown；收起态仍按原样截 3 行）。
