## 1. 🎯 "没有任务的项目还挂着胶囊条"：根因找到并修复

`MainActivity:7002`（换会话时）只清了 Java 字段：

```java
planGoal = ""; planPhase = ""; planTodos = "";   // ← 只清了自己，没清 Compose 镜像
```

而 Compose 侧的状态是 `GlassChatView.setPlanRich()` 写进去的（`state.planGoal / state.planTodos`）
⇒ **上一个会话的任务卡会串到新会话** ⇒ 看起来就是"这个项目没有任务、却还挂着一条胶囊" ✗。

**修**：换会话时把镜像一并清空：
```java
if (convo != null) convo.setPlanRich("", new java.util.ArrayList<String[]>());
```

**真机复验**：本会话（桌面侧任务为空）现在 **不显示任务卡** ✓（16 个文字节点、无 `目标…` 节点）。

## 2. 显示规则（现状，符合你的要求）

| 情况 | 行为 |
|---|---|
