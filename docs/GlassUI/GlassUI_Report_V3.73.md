## 1. "两圈"的真凶：点击手势挂错了节点

原来 `glassTap` 只挂在**头部那一行**上 ⇒ 它的**按压变暗层**比卡片小一圈
⇒ 屏幕上出现"卡片一圈 + 小灰圈一圈"= **两圈** ✗。

**修**：把点击**移到卡片本体**（与玻璃同形同尺寸）、头部那行**不再挂手势** ⇒ **只剩一圈** ✓。
（副作用可控：点卡片任意位置都能收/放，比原来只能点头部更好用。）

## 3. 玻璃质感：从"偏白洗淡"改成**浅灰磨砂体**

体色 `白 68%` → **浅色 `#EFEFEF` 86% / 深色 `#1C1B22` 86%**（磨砂 18dp 不变）。
压在正文上不再是"洗白"，而像一块**实心磨砂玻璃** ⇒ 整体质感更"实"、文字对比更好 ✓。
