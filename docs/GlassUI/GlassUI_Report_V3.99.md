## 2. 真根因

`GlassSessionList.kt` 里，抽屉的 ⋯ 原来只是**记了个状态**：

```kotlin
SmallPill("⋯", inkFaint) { state.menuFor = s }      // ← 不调宿主
...
LaunchedEffect(ws, sess) { ws != null -> …state.sheet.showList(...) }   // ← 在**抽屉自己的树**里弹
if (ws != null || sess != null) { GlassSheetOverlay(...) }              // ← 也是抽屉自己的树
```

⇒ 弹窗渲染在**抽屉面板的 Compose 树**里 ⇒ ① 永远只能居中在面板里（居不了屏 ✗）；
② **宿主那条路根本走不到** ⇒ 我 V3.97 的改动等于白做 ✗（你看到"完全没改"完全正确）。

## 3. 修

| 位置 | 旧 → 新 |
|---|---|
| 会话卡 ⋯ | `state.menuFor = s` ⇒ **`host.sessionMenu(s)`** |
| 工作区 ⋯ | `state.wsFor = g` ⇒ **`host.workspaceMenu(g)`** |
| 抽屉内自绘弹窗 | 不再被触发（`menuFor/wsFor` 恒为 null；它内部的 `hide()` 只作用于它自己那个 state，与宿主无关）|

宿主侧（V3.97 已就位）：`showGlassMenu(...)` ⇒ 走**聊天页那个 Activity 级全屏宿主**的玻璃 sheet
⇒ 形状 / 材质 / 位置与「**模型 / 权限 / 生成物 / 任务**」**完全同一套** ✓
