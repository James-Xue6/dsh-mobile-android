# GlassUI 迭代报告 V3.5 | 2026-10-08

> 触发（用户对对话页的第二轮反馈）：
> 「顶面对话栏背景怎么不动了，你看看咋回事；然后按钮和下方对应吧，也是**三个独立的**，左右是圆的中间一个独立的，
> 然后都**保持玻璃质感**，对话穿过有形变；然后所有的对话滑动，**底边一直穿到底**，穿到全面屏屏幕下边再没有，
> **不要到现在的小白条，要做成同材质的**；顶面可以加**同背景渐变，透明到实的渐变**，对话先穿过玻璃的胶囊，
> 然后逐渐消失被渐变盖住」
> 上轮：V3.4（对话页挂进 MainActivity）

---

## 1. 「顶栏背景不动」的两条原因

| # | 原因 | 处置 |
|---|---|---|
| 1 | **托管版当前是空会话**（真机没有配对设备）→ 顶栏背后没有任何内容可采样，看起来就是"一块不动的平色" | 不是 bug；有消息即会跟着糊动（`evidence/v350/02_emu_scrolled.png` 里能看到顶栏糊着「把线条推开。」） |
| 2 | 顶部**本来就缺"同材质底"**：只有玻璃件压在渐变背景上，玻璃再漂亮也没有层次 | **本轮加顶部渐变罩**（见 §2.2）：玻璃从此有一层"同背景的实→透明"材质托底，任何状态下都读得出是玻璃 |

## 2. 本轮改动（全部按用户原话）

### 2.1 顶栏 → 与底部对称的**三件独立玻璃**
`左圆玻璃「‹」(46dp) ＋ 中间独立玻璃条(52dp, 圆角 22dp, 标题/副标题) ＋ 右圆玻璃「⋯」(46dp)`，间距 8dp。
（原来是"一条通栏玻璃里嵌两个小圆"。）

### 2.2 顶部**同背景渐变罩**（透明→实）
在**取样层内**（列表之上）加一条整宽渐变：`Ui.ambientBarColor()` 实心（顶端）→ 0.86 → 全透明，
高度 = `状态栏高 + 92dp`。
- 效果：消息滑到顶部时**先穿过玻璃胶囊（被糊、被推开）**，继续往上**逐渐消失被渐变盖住** ✓
- 因为它在取样层里，玻璃**也能采样到这层材质** → 顶栏在任何状态下都有层次（正面回应「背景不动」的观感）

### 2.3 底边**一直穿到底 / 不要小白条 / 同材质**
- `MainActivity`：**Compose 屏自己管系统栏内边距** —— `setContent()` 里识别 `ComposeView`，命中则
  `applyRootInsets()` 把根容器内边距清零（旧 View 屏保持原样），并让系统栏**透明**（`applySystemBars`），
  于是环境背景/消息能**铺到屏幕最下沿**，手势条下面是**同材质**而不是一条实色小白条 ✓
- `GlassChatScreen`：不再一刀切 `systemBarsPadding()` ——
  顶部安全区只给"头部内容/玻璃件"（`topInsetDp`），列表用 `contentPadding` 让出底部手势区
  （`bottomInsetDp + 132dp`），**背景与消息本身一路画到屏幕底边** ✓
