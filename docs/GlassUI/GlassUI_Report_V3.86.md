## 1. 「还是看不到生成物」→ 加**会话级累积** ✅

`collectProducedFiles()` 原来**只扫当前历史窗口里的 `ChatItem.FILES`** ⇒ 文件一滚出窗口（或换会话回来）
面板就空了 ✗。而"这次会话产出了什么"是**会话级事实**，不该随窗口消失。

**修**：
- 新增 `sessionDeliverables`（`Map<会话ID, LinkedHashMap<key, ArtifactEntry>>`，上限 40 个会话）；
- `deliverables/presented` 事件到达时 `rememberDeliverable(...)` 记一笔（按路径去重）；
- `collectProducedFiles()` **先铺累积、再用窗口内的覆盖最新说明**。

## 2. 字号回显仍显示「中（标准）」→ 改成在**必经路径**上推送 ✅

真机版设置页的 Compose 状态是 `GlassSettingsView.state`（单一实例，见其 25/33 行）。
上一版我把推送放在了**某两个页面的构建处**，不保证每次都会走到。
**修**：移到 `applyThemeEverywhere()` —— 换主题、改字号（含 `recreate()` 后重启）**每次都会走这个方法** ⇒ 回显必定跟着更新。

## 3. 「字体变小后胶囊没跟着变小」→ 内边距按字号比例缩放 ✅

`Ui.FONT_SCALE` 只改**字**，而胶囊的内边距是写死的 dp ⇒ 字小了、壳没小，不协调 ✗。
**修**：新增 `fsDp(v) = (v × Ui.FONT_SCALE).dp`，用于**消息级胶囊**：
用户气泡（14/10）、助手卡（14/12）、思考/调用/步骤卡（14/7）⇒ 壳随字号一起缩 ✓。

## 4. 「思考/调用这些胶囊要统一大小」→ 三处统一 ✅

| 卡 | 原来 | 现在 |
|---|---|---|
| 思考过程 | `MsgCard(18dp)` + 外 6dp | **`STEP_CARD_RADIUS = 22dp`** + 外 **4dp** |
| 调用（工具行） | `MsgCard(28dp)` + 外 5dp | 同上 |
| 步骤（STEP 行） | `MsgCard(28dp)` + 外 5dp / 内 11dp | 同上（内边距也统一成 14/7，随字号缩放） |

## 5. 「对话生成物不是蓝色、点不了」—— **需要你确认位置** ⏳

我把 Chat 里的交付物卡核了一遍：**文件名用的是 `Color(Ui.BRAND_FILL)`（品牌蓝）+ 整行 `glassTap` 可点**
（V3.85 还修了"相对路径被误判为不在工作目录"⇒ 之前即使点了也只会弹提示）。
所以"不是蓝色、点不了"的元素，**很可能不是这张交付物卡**，而是：
- **工具行**里出现的文件路径（那是工具调用摘要，本来就不蓝、不可点）；或
- **生成物面板**里的行（面板里的行是灰色副标题 + 点一下弹菜单）。

**请告诉我是哪一处**（对话里那张带文件名的卡 / 工具行 / 生成物面板），我按那一处改。
