## 1. 渐变遮罩"停留在刚才" ✅（**是我 V3.91 引入的**）

V3.91 我把顶栏色改成"从上传图取色"，但 `topColor` **只在"解码图片成功"那一条路上写入** ✗
⇒ **换配色 / 取消自定义底图 / 换另一张图**时，**没有任何地方清零** ⇒ 顶栏一直停在**上一张图**的颜色 ✓
（用户描述"切换别的颜色的渐变色还停留在刚才" —— 完全吻合）。

**修**（`GlassAmbient.kt`）：

```kotlin
LaunchedEffect(imgUri) { GlassAmbientImage.topColor = 0 }   // 任何 URI 变化先清零
```

- 换成新图 ⇒ 清零后**解码成功会重新写入**该图顶部色 ✓
- 取消自定义图 / 切成内置配色 ⇒ 清零后**回落到 `Ui.ambientBarColor()`**（配色顶色）✓
- 用 `LaunchedEffect` 而不是在组合里直写状态（后者会触发无谓重组/循环）✓
