## 1. 消息里的文件名点不开 ✅（**已在模拟器验证**）

**根因**：我写的正文里是 `报告 [GlassUI_Report_V3.86.md](docs/GlassUI/GlassUI_Report_V3.86.md)。`，
而 `MarkdownText` 的行内解析**只处理 `code` / `**加粗**` / `*斜体*`，没有处理 `[名字](路径)`** ✗
⇒ 它既不是链接、也点不动。

**修**：
| 件 | 改动 |
|---|---|
| 行内渲染 | `[名字](路径)` ⇒ 正文里显示**名字**（品牌色 + 下划线），不再吐裸链接 |
| **可点胶囊** | 每块渲染完补一排**胶囊**：「打开 <名字>」⇒ 点一下调 `GlassChatHost#openPath(url, label)` |
| 宿主链路 | `openPath` → `ConversationView.Host#onOpenPath` → `MainActivity#onOpenPath` ⇒ 复用**相对路径**那条下载入口（`startDownload(relPath, name, sink, preview=true)`）⇒ **应用内预览** |
| 兜底 | `onOpenPath` 会剥掉 `< >`/引号/末尾标点；相对/绝对路径都能用（V3.85 的回退分支） |

**模拟器取证（dump）**：

打开 GlassUI_Report_V3.86.md        ← 可点胶囊 ✓

## 2. 生成物窗口无法关闭 ✅（**是我上一轮引入的**）

V3.87 我为了把 `file-list` 的异步结果补进面板，写了「15 秒窗口内**重画一遍**」✗
⇒ 你**关掉面板的瞬间**，回帧刚好到达 ⇒ `onArtifacts()` 又被调一次 ⇒ **面板又弹回来**，看着就是"关不掉" ✗。

**修**：窗口 15000ms → **2500ms**（局域网 `file-list` 往返实测 100~300ms ⇒ 该补的照样补，
但用户不可能在 2.5 秒内"打开→关闭"完 ⇒ 不会再自弹）。

## 3. 字号高亮一直停在「中（标准）」✅

**根因（比上一轮判断得更准）**：真机版设置页的状态要被宿主**推**（`settingsView.setFontScale(...)`），
而这条推送只在 `applyThemeEverywhere()` 里跑；**改字号会 `recreate()`** ⇒ 重启那一刻**设置页还没被创建**
⇒ 推送被跳过；等你再打开设置，**没人再给它推**⇒ 高亮永远停在默认 1.0 ✗。

**修**：改成**现读现用** —— `GlassSettingsHost#fontScale()`（`GlassSettingsView` 直接 `new Store(ctx).fontScale()`）
+ 设置页打开时 `LaunchedEffect(Unit) { state.fontScale = host.fontScale() }`
⇒ 高亮**永远等于库里存的值** ✓（不再依赖任何推送时机）。
