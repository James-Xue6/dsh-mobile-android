## 3. 教训（已写进规范 + 错题本）

写入 `docs/GlassUI/GlassUI_SPEC_DIALOG.md` §4（并标注旧的"体色必须显式给"作废）：

1. **共用组件不许为单一场景改材质** —— 要分场景就加**可选参数**，且**默认值必须逐字等于原行为**；
2. 改任何**跨页面复用**的玻璃件前，先 `grep` 它的调用点、**列出受影响的页面**并写进报告；
3. 观感问题优先在该场景的**容器层**解决（如抽屉底色），**不要动共用面版**。
