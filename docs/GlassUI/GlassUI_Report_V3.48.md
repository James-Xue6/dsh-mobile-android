## 0. 先回答你问的那句「这些是什么错误」

**不是错误，是「时间分隔条」**（`16:40 / 21:04 / 01:44 / …`）。它们看起来像一排报错，
是因为 **V3.47 把工具调用行整行隐藏了** —— 工具调用在你的会话里占绝大多数，删掉后就只剩这些时间戳。
同一原因也解释了你说的「消息好像有缺失」。

**已修**（`560_v348_prod.png` 实测）：
- 连续的工具调用不再逐行消失，而是折成**一行极简提示**：`1 个工具调用` / `5 个工具调用`；
- 分隔条**只在前后不都是被隐藏的工具行时**才画 ⇒ 不再出现"一屏时间戳"。

> 如果你更想「工具调用的输出也看得到」，说一声我改成"只折叠标题、保留输出"。

## 1. 一条**真 bug**：历史信息刷不出来

`GlassChatHost` 接口里**有 `loadMore()`，但 `GlassChatScreen` 从头到尾没有调用过它**
（`grep loadMore` 在整屏里只有声明、没有调用点）⇒ **滚到顶上永远不会去取更早的消息**。

**已修**：滚到列表**最顶端**（`firstVisibleItemIndex == 0 && firstVisibleItemScrollOffset == 0`）就
`host.loadMore()` 一次；`askedMore` 防重复、条目数变化或滑离顶部时复位。
**请你在真机上试**：把对话往上滑到顶，看是否拉出更早的消息。
