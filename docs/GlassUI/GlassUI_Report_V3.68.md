## 1. 磨砂加强（可读性）✅

`GlassSurface` 原本**没有磨砂参数**（写死走工程 token 的 6dp）⇒ 本轮给它加了**可选** `blurRadius`
（默认仍 = token，**行为不变、向后兼容**），然后目标卡：

| 参数 | 旧 | 新 |
|---|---|---|
| 磨砂 `blurRadius` | 6dp（token 默认） | **14dp** |
| 体色 `tint` | 白 55% | **白 72%** |

（两个质感数值，符合 SOP"一次 ≤2 个"。）
**真机证据**：`evidence/phone-20261011/881_expanded_zoom.png` —— 卡背后正文只剩淡淡轮廓，
**任务行与状态文字清晰可读** ✓。

## 2. 「点击收不回去」✅（根因是我自己的取证钩子）

**根因**：上一版写成 `val planOpen = planOpenLocal || GlassDebug.forcePlanExpanded`
⇒ **只要启动时带了取证钩子 `--ez glass_force_plan true`，就永远展开、点也收不回** ✗
（而我为了截图**正是带钩子启动的**，真机实测就是这个现象）。

**修**：钩子只做**开场展开一次**（`LaunchedEffect(force) { if (force) planOpenLocal = true }`），
之后**点击自由收/放**。
