## 1. 根因：我把"取层优先级"和"过期层"混在一起改了

**V3.113 之前（V3.104，用户确认过"质感调过去了"）**：抽屉弹窗的取样层 = `GlassChatBackdrop.layer`（聊天页主取样层）
→ `GlassDrawerBackdrop.layer`（抽屉自己那层）作为兜底。

**V3.113 我改成了**：只认 `GlassDrawerBackdrop.layer` ✗ ⇒ 于是抽屉 ⋯ 弹窗采的是**抽屉自己那层**，
材质明显更弱 ⇒ 就是用户看到的"**玻璃质感没修复**"。

⚠️ 关键区分：V3.113 真正要修的**只是"过期层"**（聊天页切走后层还在 ⇒ 采样出空 ⇒ **透明** ✗），
那一条已经由 `GlassChatScreen` 的 `onDispose` 清空修掉了 ✓。**取层优先级不属于那个 bug，我不该顺手改** ✗。

## 2. 修复（V3.116）

`glass/GlassSessionList.kt · createGlassSheetHost` 取层优先级**回到 V3.104**：

```
layer = GlassChatBackdrop.layer ?: GlassDrawerBackdrop.layer
if (layer != null) { GlassSheetOverlay(backdrop = layer, state = drawerSheetState, ...) }
```

- ✅ 抽屉弹窗是**整屏**浮层，它背后就是"聊天页 + 抽屉" ⇒ 采**聊天页那层**才是正确观感（= 用户认可的材质）✓
- ✅ 仍然保留两条保护：① 拿不到任何有效层 ⇒ **什么都不画**（宁可回退旧弹窗，不画透明玻璃 ✓）；
  ② 状态**仍是抽屉自己那套**（V3.114 ✓）⇒ 位置在**抽屉面板之上**、且不会和聊天页重复渲染 ✓
