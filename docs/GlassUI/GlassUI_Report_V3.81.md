# GlassUI 迭代报告 V3.81 | 2026-10-11（对话不许折叠 · 完整/精简有区别 · 新增字体大小三档）

> **触发**：用户「对话内容**不要能折叠**，只有思考调用这些是带折叠的；设置里面**完整和精简为什么没有区别了**——
> 完整是思考调用这些**展开**，精简是**默认折叠**；设置里再加一个**字体大小**（大/中/小三档，目前是标准档）」。

---

## 1. 对话内容不再折叠 ✅

`AssistantCard` 原来带「3 行摘要 + 收起/展开按钮 + 整卡可点收放」✗
⇒ 按用户要求**全部移除**：助手正文**永远全展开**（走 Markdown 渲染）。
折叠只保留在**「思考过程」卡**与**「工具调用」行**（各自有自己的开合状态）。

## 2. 完整 / 精简：现在真的有区别 ✅

**根因**：`MainActivity` 早就调 `convo.setCompact(mode == "compact")`，但 `GlassChatView.setCompact()`
**只转发给旧视图**（做可见行过滤），**没有镜像给 Compose** ⇒ Compose 侧两条路的"思考/工具行"
都是同一个默认（收起）⇒ 看起来没区别 ✗。

**修**：
- `GlassChatState.compact` 新增；`GlassChatView.setCompact` 里 `state.setCompact(value)`；
- `GlassChatScreen` 把 `verbose = !state.compact` 传进 `ChatRow` ⇒
  **完整**：`ThinkingCard` / `ToolCard` 的 `startOpen = true`（开场即展开）；
  **精简**：`startOpen = false`（开场收起，用户仍可点开）。
- 行数过滤仍由旧视图 `applyFilter()` 负责（精简时工具行本身就不会铺出来）。

## 3. 新增：字体大小（小 / 中 / 大）✅

| 层 | 改动 |
|---|---|
| `Ui` | 十个字号常量 **从 `final` 改为可调** + `applyFontScale(scale)`（统一比例缩放，层级比例不变） |
| `Store` | `fontScale()` / `setFontScale()`（存**比例**：小 0.9 / 中 1.0 / **大 1.12**；越界退回标准档） |
| `SettingsView.Host` | 新增 `onSetFontScale(float)` |
| `MainActivity` | 启动时 `applyFontScale(store.fontScale())`（放在 `applyThemeEverywhere` 里，**建视图之前**）；用户改档 ⇒ 落库 + 应用 + `recreate()`（字号是"所有页面每处文字"都读的常量，重建最能保证不漏） |
| `GlassSettingsHost` | 新增 `pickFontScale(scale)`；`GlassSettingsView` 转发 |
| 设置页 UI | 「外观」卡里新增 **「字体大小」** 三分段：小 / 中（标准）/ 大（当前档高亮） |
