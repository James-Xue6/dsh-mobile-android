## 1. 批注①：根因 = **设置页的取样层里只有背景，没有内容**

```kotlin
// 改前 GlassSettings.kt
Box(Modifier.fillMaxSize()) {
    Box(Modifier.fillMaxSize().layerBackdrop(backdrop)) {        // ← 层里只有这一块渐变
        AmbientBackground(Modifier.fillMaxSize(), rev = state.themeRev)
    }
    Box(Modifier.fillMaxSize()) { Column { …整页内容… } }        // ← 可滚动内容在层外
    Row { 顶栏（两个 RefractionWindow，取 backdrop） }             // ← 悬浮玻璃
}
```

悬浮玻璃的玻璃感来自「**模糊/折射到从它底下滑过去的内容**」。层里只有一块**平滑渐变**，
糊了等于没糊 ⇒ 只剩体色 + 亮边 ⇒ 用户看到的「玻璃感没了」。

对照：**对话页是对的** —— `Box(layerBackdrop) { AmbientBackground; LazyColumn }`，层里是「背景 + 内容」，
所以对话页顶栏能糊到气泡。这正是**交接须知 §1 第 1 条**：*取样层 = 背景 + 可滚动内容，玻璃件留在层外*。

### 1.1 决定性取证（不是"看着像"）

判据：**同一个顶栏件，在两个不同滚动位置下，内部像素该不该变？**
层里只有静态背景 ⇒ 必须逐像素相同；层里有内容 ⇒ 必然变化。

| 测量区域 | 改前（旧包） | 改后（新包） |
|---|---|---|
| 标题胶囊右侧空白区：未滚动 vs 已滚动 | **平均差 0.00 / 最大 0**（逐像素相同） | 平均差 2.43 / 最大 6 |
| `‹` 圆钮内部：未滚动 vs 已滚动 | 平均差 **0.84**，差>6 的像素 **4.3%** | 平均差 **19.02**，差>6 的像素 **75.8%** |

⇒ 改前顶栏对内容**彻底无感**（0.00 是铁证）；改后 75.8% 的像素随内容变化。

## 2. 修法：**两层取样**（最小改动，内容里的玻璃卡片一行没改）

为什么不能简单地把内容塞进同一个层：内容里的卡片**本身是真玻璃**
（`SectionCard` / `FieldRow` / `GhostButton` / `Segmented` 都用 `RefractionWindow`）⇒
放进**同一个**层会**自取样**（工程既有记录：那样"卡片里看不到背景，一片平白"）。

所以分两层：

| 层 | 内容 | 谁用 |
|---|---|---|
| `backdrop`（内层，原样保留） | **只有背景** | 内容里的真玻璃卡片（**一行代码都没改**） |
| `pageBackdrop`（新增外层） | **背景 + 可滚动内容** | **层外**的悬浮件：顶栏两个胶囊 + 日志浮层 |

```diff
  val backdrop = rememberLayerBackdrop()
+ val pageBackdrop = rememberLayerBackdrop()      // 只给层外悬浮件用（背景 + 内容）
...
- Box(Modifier.fillMaxSize()) {
+ Box(Modifier.fillMaxSize().layerBackdrop(pageBackdrop)) {   // 内容层 = 取样层
      Column(Modifier.fillMaxSize().verticalScroll(scrollState)…) { …整页内容… }
+ }
+ // ↓ 顶栏与日志浮层**移出内容层**（放进层里会自取样"一片平白"），并改取 pageBackdrop
  Row(…) { RefractionWindow(backdrop = pageBackdrop, …) ; RefractionWindow(backdrop = pageBackdrop, …) }
- if (state.logOpen) LogOverlay(backdrop, …)
+ if (state.logOpen) LogOverlay(pageBackdrop, …)
```

**验证**：卡片外观**未变**（`302` vs `311` 的卡片区一致）；顶栏玻璃感恢复（§1.1）；`crash=0`。

## 7. 踩坑（新增）

1. **`layerBackdrop` 的层里放什么，决定玻璃件"有没有东西可糊"**。只放背景 ⇒ 悬浮玻璃必然变成"体色 + 亮边"，
   而且**滚动时纹丝不动**（本轮用它当判据）。给悬浮件单独做一层（背景 + 内容），
   内容里的真玻璃继续用内层 —— 两层法可以既不破坏卡片、又让悬浮件糊到内容。
2. **测"玻璃有没有糊到内容"别量含图标/文字的件**（那些像素起伏来自图标本身，把信号淹掉）：
   要么量**空白区**，要么用"两个滚动位置的差"这种**只对内容敏感**的判据。
