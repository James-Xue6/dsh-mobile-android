## 1. 弹窗"变形"：根因 + 根治 ✅（**已在模拟器验证**）

**根因**：之前（V3.48）为了把抽屉里的弹窗"挪到屏幕中心"，用了

```kotlin
val shiftDp = (screenWidthDp.dp - maxWidth) / 2f      // maxWidth = 抽屉面板宽度
Box(Modifier.fillMaxSize().padding(start = shiftDp * 2)) { GlassSheetOverlay(...) }
```

抽屉面板只有 ~360dp，而 `shift` 常是 200dp+ ⇒ **`2×shift` 直接超过面板宽度** ⇒
弹窗可用宽度被压到 0 附近 ⇒ **退化尺寸（= "变形"）**，位置也更怪 ✓✗

**根治**：**去掉那个 padding**，弹窗按面板宽正常渲染、在面板内居中。
模拟器取证（`evidence/v3940_menu.png`）：面板尺寸正常、内容完整（
「程序开发 / F:\AI\程序开发 / 在此工作区新建任务 / 关闭」），**不再变形** ✓✓

## 2. 抽屉白底 → 微主题色（很弱）✅ + 玻璃加厚 ✅

`DrawerHost.applyDrawerBg()` 里、**只在抽屉这一处调用**（不动 `GLASS_SHEET` 全局 token，
避免设置页折叠卡/底栏连坐）：

| 件 | 旧 → 新 |
|---|---|
| 白底 | `GLASS_SHEET` ⇒ **`GLASS_SHEET` 混 8% 品牌色**（`blend(...)` 新增工具函数）|
| 不透明度 | `0.82` ⇒ **`0.90`**（更厚、更不透明 ⇒ "太透明"缓解）|
