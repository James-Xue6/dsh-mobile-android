【本轮原始问题描述】
> 用户：左右为啥有个黑色带？还有变形还是有点不太对呢，变形折射区域是不是太窄了？

【差异分类 & 量化差异清单】
1. **A质感**：折射环带 **16% → 24%**（用户：折射区域太窄）。
2. **B布局（调用处，测试页）**：色块列与玻璃覆盖层**改满宽**（原左右各留 10dp / 14dp）。原因：左右留白处是页面深色底，玻璃边缘采样到的就是那圈深色 → 看着像"左右黑带"。改满宽后玻璃边缘直接压在色块上，黑带消失（详见 `DG1-环带24满宽.png`）。
   - 注：这属 B 类（布局），不改质感 Token、不动组件本体，符合 SOP 第 3 条。

【本轮代码变更摘要】
- 修改文件：`proto/FrostedPanelView.java`（环带比例 0.16f → 0.24f，1 个数值）；`proto/GlassAlignActivity.java`（两处 padding 改 0，B 类调用处）
- 最小变更：符合"单次 ≤2 个 Token 数值"。

【重要存档备注】
1. 环境背景：选型页 = 全宽多彩长栏（含纯黑气泡）+ 上层 4 块固定玻璃（全宽）。
2. 平台信息：模拟器 Pixel_7_API35；真机 PGT_AN10 待重连。
3. 踩坑累积：① 折射符号必须为正；② 环带/幅度必须随面板尺寸缩放；③ padding 要 2.35× 环带；④ 抓取源 targetRoot 且补偿 0；⑤ 共享抓取隐藏全部玻璃件；⑥ 抓取期间停画外投影；⑦ **测试页留边距会让玻璃边缘采到页面底色，像"黑带"**。
4. 待解决：① 白度 A/B/C/D 待拍板；② 24% 是否合适；③ 真机复验；④ "背景残留"未定位。
