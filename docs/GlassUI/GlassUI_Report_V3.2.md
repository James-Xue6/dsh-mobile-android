> 下面的这个也不需要这个大长条，就**左侧圆玻璃、右边发送圆玻璃、中间是圆角长条输入条**，**都是玻璃质感**，

> 上轮：V3.1（按压反馈）　**验收：模拟器取证 + 真机复装**

---

## 1. 定性：两件事

### 1.1 「滑上去没有玻璃质感」的**根因**：内容没进取样层
上一版把 `Modifier.layerBackdrop(backdrop)` 只铺在**环境背景**上，滚动消息在**层外**：
⇒ 玻璃永远只能糊到一片平滑渐变，**内容从它下面滑过时既不被糊、也不被推开**。
所以"看着没有玻璃质感"不是质感参数问题，是**结构问题**。

**修法**：取样层 = **环境背景 + 可滚动消息**；玻璃件一律留在**层外**（否则会把自己也取样进去）。
> 这也是正式版的做法：`FrostedPanelView` 的抓取源是**滚动容器**（列表），所以列表滚过时顶栏/输入条里能看到糊掉的消息。

### 1.2 底部布局：去掉整条磨砂板 → 三个独立玻璃件
| | 改前 | 改后 |
|---|---|---|
| 底部 | 整条 `GlassSurface(radius = 0)` 磨砂长板 + 里嵌一个胶囊 | **左圆玻璃「＋」(38dp) + 中间圆角玻璃输入条(46dp, 圆角 22dp) + 右圆玻璃「↑」(38dp)**，三件各自独立 |
| 子智能体入口 | 平色 `clip + background(BRAND_SOFT)` 胶囊 | 独立**玻璃胶囊**（`RefractionCapsule`） |
| 顶部 | 圆角玻璃条（22dp）—— 形态不变 | 同形态，但**现在真的会糊背后的内容** |

### 1.3 消息卡为什么改成"半透明卡"
消息现在**在取样层里**；如果消息自己也是真玻璃，就会读到"包含自己的那一层"（自取样 → 鬼影/递归）。
正式版同样是这么分的：**消息气泡是半透明 `CardBg`（`Ui.GLASS_CARD` = 浅色白 26% / 深色 `#14121C` 30%）**，
只有顶栏 / 输入条这类**悬浮件**才是真模糊（Frost）。本页照抄：消息 = 半透明卡 + 发丝线；悬浮件 = 真玻璃。

| 区域 | 滚动一次后的变化像素 |
|---|---|
| **顶栏玻璃区**（y 60–210） | **50821 / 162000**（≈31%） |
| **底部三件区**（y 2160–2320） | **59201 / 172800**（≈34%） |

## 3. 与设备页的差异（说明，不是遗漏）

设备页的"内容"就是那些**玻璃卡本身**，不能进取样层（会自取样），所以设备页仍是"玻璃只取样背景"。
这与正式版一致（正式版设备页的卡片是 `FrostedPanelView`，抓取源是根容器背景）。
如果后续想让设备页的**页脚/空态文字**也能被卡片糊到，需要把"非玻璃内容"单独拆一层，属可选优化。
