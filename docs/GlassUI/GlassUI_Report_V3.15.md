## 1. ✅ Bug 1：添加设备弹窗"左右两侧有多余的框" —— 已修并验证

**根因**：面板原来左右各留 10dp 内缩 ⇒ 玻璃件的**外阴影在两侧显形**，看着像"页面背景被缩小、四边多出框"。

**修法**：面板改**通栏**（`.padding(bottom = 0.dp)`，去掉左右内缩）⇒ 外阴影落到屏幕外。

**验证**：`evidence/v3215/02_sheet_fullwidth.png` —— 面板铺满屏宽、两侧干净无框，抓杆/标题/两项/取消正常。

## 2. ✅ Bug 3：首页右上齿轮没有按动反馈 —— 已修

**根因**：`GearButton`（在 `GlassDevicePageActivity.kt`，两屏共用）是 **36dp 里塞 9dp 图标**
⇒ 按动缩放几乎看不见。

**修法**：`size(36.dp)` → **`size(44.dp)`**、图标 `9.dp` → **`20.dp`**，并显式给
`glassTap(corner = 22.dp)`（与其它玻璃按钮同一套按压反馈）。

**验证**：`evidence/v3215/01_device_gear.png`（模拟器；真机待装后复看按动缩放）。

## 3. ⏳ 仍未做（2 项，已定因，下一步照做）

### Bug 5：顶栏/设置导航栏滑动没玻璃质感 + 玻璃按钮阴影偏弱
- **已确证**：`GlassSettings.kt` 的**取样层里只有 `AmbientBackground`** ⇒ 顶栏/分区卡只能采到静态背景，
  滑动内容不参与 ⇒ "没有玻璃质感"。
- 下一步：① 把**可滚动内容挪进取样层**，同时把层内的分区卡/输入行/分段从 `GlassSurface`/`RefractionCapsule`
  换成**半透明卡**（V3.2 层内规则，否则层内真玻璃会自取样）；② 给 `RefractionWindow` 加
  `shadowAlpha: Float = 1f`（默认不变），玻璃按钮略调高、弹窗略调低 —— 一次受控阴影调参（SOP ≤2 值）。

### Bug 2：「手动添加」进去还是老界面
- **已定位**：`onManualAdd()` 走旧 Java 对话框。
- 下一步：骨架加**表单形态** `showForm(tag, title, fields, primaryLabel)`（内网/公网/令牌/设备名 四个输入 +
  保存/取消），`sheetPick` 把字段值回传宿主，接 `onConnect(...)` 真流程。
