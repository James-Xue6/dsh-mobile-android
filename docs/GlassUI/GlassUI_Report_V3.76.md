## 1. Markdown 结构排版：按手机宽度重排 ✅

**根因**：表格原来**按列等分宽度**（`weight(1f)`）⇒ 手机上每格很窄、大量折行 ⇒ **又长又难读** ✗。

**改法**（`MarkdownText.kt` 的表格渲染）：

| 表格列数 | 新排版 |
|---|---|
| **≤ 2 列** | 渲染成**键值行**：左 34% 标签（小字/次要色）+ 右 66% 值（正文色），行间一条 0.5dp 细线 |
| **≥ 3 列** | 渲染成**逐行紧凑文本**（` · ` 分隔），表头单独一行小字当标题 + 细线 |

**真机（模拟器）取证**：`evidence/v3760_md_table.png`
—— `### 取样层次（两列键值）` 渲染成**加粗标题** ✓、下面的两列表格变成**键值行** ✓、
`### 三列表格（走紧凑行）` 同样成标题 ✓；行内代码 `` `backdrop` `` 也正常（无刻度线残留）✓。

## 2. 交付物：**点击=打开预览**，预览页里再「保存」✅

**取证发现**：工程里**两条路本来就有** ——
`d.preview = true` ⇒ 下到 App 私有预览缓存并 `openArtifactPreview()`；`false` ⇒ 存进手机「下载」目录。
问题是**交付物行把"点击"直接绑到了下载**（`downloadFile`）✗。

**改法**（6 处）：

| 文件 | 改动 |
|---|---|
| `GlassChatHost` / `GlassChatScreen` | 新增 `previewFile(item, path)`；交付物行：**点击 = 打开预览**、**长按 = 下载到手机**；提示文案改成「点此打开 · 长按下载到手机」 |
| `ChatAdapter.Host` / `ConversationView.Host` / `ConversationView` | 新增 `onPreviewFile` 并转发（旧视图同样受益） |
| `MainActivity` | `startDownload(item, path, previewInApp)`：`true` ⇒ 落预览缓存并打开；新增 `onPreviewFile` |
| `GlassChatView` | 转发 `previewFile` |
| **`ArtifactActivity`（预览页）** | 顶栏新增 **「保存」按钮**：把**已在预览缓存里的文件**直接复制进手机「下载」目录（MediaStore.Downloads；旧版本走 `Environment.DOWNLOADS`）—— 不用回网关再下一次，**离线也能存** ✓ |

⇒ 结果就是你要的：「**愿意保存的就保存，不愿意就直接打开看**」✓
