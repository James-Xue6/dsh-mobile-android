## 2. ⭐ "目标看不到"定论（数据侧，非 App 问题）
日志页现场证据（`v3270/420~423`，98 行，滚到底）：
```
evt step/start …  evt assistant/message …  evt tool/call …
tasks 帧 sid=1e1c526b n=null      （两次）
```
- **整份日志里没有任何「目标帧」记录** ⇒ `applyGoal()` **从未被调用** ⇒ **网关没给该会话推过 goal 帧**；
- `tasks 帧 … n=null` ⇒ **任务帧无 todos** ⇒ 也解释「任务 0/0」。
- App 侧已加**自证留痕**（`applyGoal` 里写 `keys/objective.len/前24码元` → 事件流 → 日志页），
  下次打开日志页即可对质"收到没收到"。
