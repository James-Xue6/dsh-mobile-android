# GlassUI 迭代报告 V3.80 | 2026-10-11（复制路径改成明面按钮 · 裁剪页框外压暗 + 顶栏避让状态栏）

> 还有发送图片裁剪建议**选框外变成灰色**这样对比明显些，还有上方**取消和完成太高了，到手机状态栏上面了**，往上挪挪」。

## 1. 交付物复制：不再依赖"长按"，改成**明面按钮** ✅

**先查了代码，链路其实是通的**：
- `glassTap(corner, onLongClick, onClick)` 确实用 `combinedClickable` 把长按透出去了（`GlassAmbient.kt:604-613`）；
- `onCopyPath` 也确实在写剪贴板 + 弹「路径已复制」（`MainActivity:5761`）。

**那为什么用户"没法复制"**：长按是**隐式手势**——而 `glassTap` 按下时还有 **0.96 的缩放反馈**，
所以观感就是「**长按变小了 / 像个按钮，但没复制**」✗（长按的判定窗口和用户的按法对不上）。

**修**：交付物行上摆**两个看得见的胶囊按钮**：

| 按钮 | 行为 |
|---|---|
| **打开** | `previewFile` ⇒ 落私有预览缓存并打开预览页（页内还有「保存」）|
| **复制路径** | `copyPath` ⇒ 直接写剪贴板 + toast「路径已复制」|

（长按保留为附加入口；`打开` 的提示行不再占位。）

## 2. 裁剪页：框外压暗 ✅

原来框内外**没有对比** ⇒ 现在框的**上/下/左/右四块**都盖 `黑 55%`，随框实时变化 ⇒ 选框内外一目了然。

## 3. 裁剪页：顶栏避让状态栏 ✅

`edge-to-edge` 下内容会画到状态栏底下（用户报「取消/完成到状态栏上面了」）
⇒ 顶栏加 `statusBarsPadding()`（+ 原有 12dp 内边距）。
