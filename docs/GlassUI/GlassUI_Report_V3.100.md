# GlassUI 迭代报告 V3.100 | 2026-10-11（弹窗层级：从抽屉点出来的菜单被压在抽屉下面）

> **触发**：用户「**界面没问题，但是弹窗层级位置不对，应该在最上层，现在在对话位置，在下层了**」。

---

## 1. 根因：视图层级（不是渲染内容的问题）

| 层 | 是什么 |
|---|---|
| 最底 | 聊天页（`MainActivity` 的内容，含**所有**玻璃弹窗的宿主 `GlassChatView`）|
| **上面一整层** | **抽屉**：`DrawerHost`（FrameLayout：内容 + 遮罩 + 抽屉面板）|

⇒ 玻璃弹窗渲染在**聊天页**那棵 Compose 树里 ⇒ 从**抽屉**里点出来的菜单，会被**抽屉整层盖住** ✗
（上一轮我把菜单改成回调宿主、走全屏玻璃弹窗 ✓，但忘了它还压在抽屉下面 ✗）。

## 2. 修：弹窗弹出前**先把抽屉收起** ✅

```java
// MainActivity#showGlassMenu
if (drawerHost != null && drawerHost.isOpen()) drawerHost.closeDrawer(true);
```

抽屉收起后露出全屏的聊天层 ⇒ 弹窗 + 遮罩自然成为**最上层** ✓。
（弹窗本身是**模态**，收起抽屉不损失信息：菜单标题就是那条会话/工作区名 ✓。）
