【本轮原始问题描述】
> 用户：左右有一节脱节的位置，左右是没有扭曲变形的，应该是一圈然后柔和地过渡到内部。
> 用户（关键补充）：和你背景色关系不太大，这个反射边缘往外、左右都有，**又变回卡片颜色了**。

【差异分类 & 量化差异清单】
1. **A质感（根因）**：`applyLens` 采样**越界回退**。原来 `if (x0<0||y0<0||x0>=W-1||y0>=H-1) { out=in; continue; }` ——
   面板离屏幕边近（测试页只留 10dp，折射要往外采 28dp）时，坐标越过**已捕获位图**范围，
   越界处是未初始化的透明像素 → 叠上玻璃自身 tint = 左右两条发白竖带（用户："变回卡片颜色"）。
   **修法：夹进位图范围取最近真实像素**（不再回退原像素——那会形成硬边，正是 V0.3"很硬的变形边缘"的成因之一）。
2. B布局（测试页，调用处）：左右留 10dp 边距 + 页面底改彩色（保证玻璃外侧有内容可采、且不是深色"黑条"）。

【本轮代码变更摘要】
- `proto/Frost.java`：applyLens 越界回退 → 夹位图范围（4 行）
- `proto/GlassAlignActivity.java`：边距 10dp + 彩色底（B 类）

【重要存档备注】
1. 新增机制结论（务必记住）：**折射采样必须夹在"已捕获位图"范围内**；面板离屏幕边 < 折射幅度时，越界区无内容 → 会出现"发白竖带/变回卡片颜色"。
2. 面板外侧至少要有 ≈ 折射幅度（当前 38px≈15dp）的可见内容，否则该侧无有效形变或出现伪影。
3. 参照优先级：Demo 实测 > 规范文字；规范 §二-45/46 的 0x59/0x80 与 Demo 的 0x42/0x1E 矛盾，且 applyLens 的负号已证伪 —— 三处建议回写规范（待用户批准）。
