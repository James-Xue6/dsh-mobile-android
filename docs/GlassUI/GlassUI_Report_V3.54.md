## 3. 为什么"不显示"和这件事是同一件事

真机 `evidence/phone-20261011/700_after_patch_chat.png`：**整页只有顶栏 + 输入区，中间全空**
⇒ 那个会话（老 v2 会话）内容是**读不出来**的 ⇒ **目标卡与任务胶囊根本不会渲染**。
所以"任务胶囊质感还没调"很可能是**看不到它**，而不是"看到了但没变"。
