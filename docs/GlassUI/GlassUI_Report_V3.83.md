## 1. 长按：改回**手机自带的选取/全选** ✅

上一版我做成"长按整条复制"，不是用户要的 ✗。现在用 `SelectionContainer` 恢复**原生文本选择**
（长按出选择手柄 + 系统「复制 / 全选 / 搜索」菜单）：

- **用户气泡**：`SelectionContainer { Text(...) }`
- **助手正文**：`SelectionContainer { MarkdownText(...) }`

⚠️ **历史事故提醒**：V3.57 曾把 `SelectionContainer` 包在 **LazyColumn** 上，结果**杀掉头块与消息**。
这次只在**每条消息的 item 内部**包（不碰列表）⇒ 不会重演。

## 2. 字号"选了不生效 / 不回显"——两个不同的原因 ✅

| 现象 | 根因 | 修复 |
|---|---|---|
| 选了「小」，进设置**还显示中** | `MainActivity` 从来没把库里存的字号推给 Compose 设置页 ⇒ 高亮一直是默认 1.0 | `GlassSettingsView.setFontScale()` + 宿主启动时 `settingsView.setFontScale(store.fontScale())`；`SettingsView` 加空实现保持编译 |
| 选了字号**界面不变** | `Ui.S_*` 是**静态常量**，Compose 只在**组合时**读一次；切片里原地 `rebuild()` 不能保证所有已组合节点重读 | 切片改用 **`recreate()`**（与主题切换同款，重建 Activity 一处不漏）；真机版本来就是 `recreate()` |
