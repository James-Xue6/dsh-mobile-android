【本轮原始问题描述】
> 用户：扭曲变形的位置过度异常、不自然，希望逐渐往里延伸、形变慢慢消失。
> 用户（关键）：我发现问题了，**是你的扭曲做反了** —— 我把边缘放到黑色位置，它不显示黑色。

【差异分类 & 量化差异清单】
1. **A质感（根因）**：折射符号 **-refrAmount → +refrAmount**。原代码 `applyLens(..., -refrAmount/ds, ...)` 使位移向内（等于放大面板内部内容），所以边缘放到黑色背景上也不显示黑；正确应向外采样、显示边缘背后的真实内容。这也解释了"padding 怎么加都看不出效果"——向内采样根本用不到溢出区。
2. A质感：环带比例 **22% → 16%**；幅度 **1.35× → 0.5×**（峰值位移减半，过渡更柔和、逐渐消失）。

【本轮代码变更摘要】
- 修改文件：`proto/Frost.java`（2 处 applyLens 调用的幅度符号）、`proto/FrostedPanelView.java`（lensRefrHeight/lensRefrAmount 两个数值）、`proto/GlassAlignActivity.java`（测试页加纯黑气泡，供黑区判定）
- 修改内容（最小变更）：符号 ×2 + 比例 ×2，组件绘制顺序未动、未重构。

1. 环境背景：极光底图（根容器 AmbientDrawable）；选型页 = 多彩长栏（内容，可滚动）+ 上层 4 块固定玻璃。

3. 重要约束/踩坑：① 折射符号必须为正（向外采样），否则"边缘不显示背后的颜色"；② padding 必须容下位移（2.35× 环带）；③ 抓取源 targetRoot 且补偿 0；④ 共享抓取要隐藏全部玻璃件；⑤ 抓取期间停画外投影。
