## 1. ① 位置变形 + 未玻璃化

### 1.1 原因
- **未玻璃化**：底部能力 chip（权限/模型/思考）用的是 `Modifier.background(Ui.CHIP_BG)` **平色胶囊**（与抽屉按钮同款问题）。
- **位置变形**：那些小元件（38dp 的子智能体胶囊、38dp 圆钮）**沿用了默认折射**（`RefractionHeight 14dp` /
  `RefractionAmount 28dp`）——折射带比元件高度还大，镜头把里面的标签/图标推挤得看着"变形"。

### 1.2 修法
1. **小尺寸元件压低折射**：给对话页的 `SubagentChip`、`GlassRoundButton`（＋/↑ 圆钮）显式传
   `refractionHeight = 6.dp, refractionAmount = 8.dp`（**调用处入参**，不动全局 token）。
2. **chip 玻璃化**：改成"玻璃观感"三件套（斜向半透明白渐变 + 0.5dp 发丝边 + 定高 30dp）。

### 1.3 踩坑（重要）
第一版我直接把 chip 换成真玻璃 `RefractionCapsule` ⇒ **更糟**：`RefractionWindow` 内部是 `BoxWithConstraints`，
**只给高度约束时会撑满父宽** ⇒ 三个 chip 变成三条通栏胶囊互相叠住（证据 `v3230/01_chat_chips.png`）。
⇒ 结论：**小尺寸、需要"内容自适应宽度"的元件不要直接套玻璃节点**，用"玻璃观感"或不给玻璃节点。
（这一条已写进代码注释，避免后人再踩。）

## 2. ② 上方渐变位置过低 —— 已修

顶部渐变罩原来高 `topInset + 92dp`（比顶栏胶囊下缘还低 70 多 dp）⇒ 渐变盖到了胶囊下面。
改为 **`topInset + 18dp`**：渐变正好**收在顶栏胶囊的上边缘**，往下是干净的页面。
