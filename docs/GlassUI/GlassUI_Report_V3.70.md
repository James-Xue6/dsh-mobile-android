# GlassUI 迭代报告 V3.70 | 2026-10-11（"点击时下方对话跟着动" + "纯白没磨砂" —— 根因与修复）

> **触发**：用户「现在点击这个目录任务，**下方对话怎么跟着动**？应该不影响，是**单独的层**。
> 还有现在的**质感纯白色**了，完全不是磨砂质感的」。

---

## 1. 两个现象是**两个不同的根因**

### ① 点击时下方对话跟着动 ✗
卡片在**头块**里，而列表的 `contentPadding.top = 头块实测高度（headDp）`
⇒ 卡片一长高，`headDp` 变大 ⇒ **整列消息被推下去** ⇒ 看起来"下方跟着动" ✗（不是独立层）。

### ② 质感纯白、没磨砂 ✗ —— **是我上一轮改出来的**
V3.69 为防"正文透过来"，我把取样层换成了**只含环境背景**的 `ambientBackdrop`。
但**那一层里没有内容可糊** ⇒ 玻璃没有东西可以模糊 ⇒ **就是一块平白** ✗（"纯白"由此而来）。

## 2. 修复

| # | 改动 | 效果 |
|---|---|---|
| ① | 卡片外面加 **固定占位 `Box(Modifier.height(50.dp))`**（Compose 的 Box **默认不裁剪** ⇒ 卡片超出部分**溢出绘制在上层**） | 头块高度**恒定** ⇒ **展开时下方对话一动不动** ✓ |
| ② | 取样层**改回内容层** `contentBackdrop`（层里有正文 ⇒ 有东西可糊） | 恢复**真正的磨砂** ✓ |
| ③ | 磨砂 **18dp** + 体色 **68%**（两个质感数值） | 压在正文上也读得清 ✓ |
| ④ | 删掉 V3.69 引入的 `ambientBackdrop` 层 | 不留死代码 ✓ |
