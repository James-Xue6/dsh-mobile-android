# GlassUI 迭代报告 V3.55 | 2026-10-11 凌晨（补丁安装器两处真 bug：LF 行尾 + 守候轮询太慢）

> **触发**：用户「我重启了，你桌面的这个我点击就闪一下就没了」。
> **结论**：**两个真 bug**，都已定位、修复并用"临时副本"自测通过。

---

## 1. bug ①：桌面 `.bat` 点击即闪退 —— **行尾是 LF**

实测字节：`40 65 63 68 6F 20 6F 66 66 0A`（`@echo off` 后是 **0A**）。
**cmd 的 .bat 必须 CRLF**（LF-only 会让 cmd 逐字节吞命令 ⇒ 窗口一闪就退）。
**修**：转成 CRLF（校验：CR 总数 = CRLF 数 = 110，裸 LF = **0**，无 CRCR）。

## 2. bug ②：守候装不上 —— **5 秒轮询睡过了窗口**

日志只有一行 `02:21:43 watcher started`，而 DSH 在 **02:24:11** 重启（关机窗口只有一瞬间）
⇒ 5 秒轮询**正好没落在窗口里**。
**修**：轮询 `Start-Sleep -Seconds 5` → **`-Milliseconds 700`**，已 `Stop`+`Start` 重启守候
（新日志行 `02:26:29 watcher started`，State=Running）。

## 3. 新增：**一键安装器**（自己关 DSH，不靠运气）

`tools/dsh-asar-patch/安装补丁-一键(会重启DSH).bat`（CRLF；桌面同名副本已就位）：
```
5 秒倒计时(可关窗取消) → taskkill 关闭 DSH → 探测档案句柄释放(最多 60s)
→ 备份 app.asar → 装入 app.asar.patched → 校验大小 == 121348401
→ 自动 start DSH；任一步失败自动回滚
```
**自测**（把顶部 4 个参数换成临时目录的哑文件，**不碰真档案**）：
`app.asar`(100B) + `app.asar.patched`(140B) → 跑完得到 `app.asar`=**140B**、
`app.asar.bak-20261011-022611`=**100B**、校验行打印 `140 字节（期望 140）` ✓ 全流程通过。
